🎓 University Database Management System

📌 Overview
A simple university database project developed using MySQL. The project demonstrates basic database design, table relationships, and SQL queries to manage university-related data.

🗂️ Database Tables
The database consists of four main tables:

-Student – Stores student information.

-Course – Stores course details.

-Instructor – Stores instructor information.

-Room – Stores classroom information.

⚙️ SQL Features

-Table creation and relationships

-Primary and Foreign Keys

-SQL Joins

-Aggregate Functions (COUNT, SUM, AVG, etc.)

-Views

-Basic SQL Queries

🛠️ Technologies Used

-MySQL

-SQL

🎯 Purpose

This project was created to practice relational database concepts, SQL queries, and data management using MySQL.
